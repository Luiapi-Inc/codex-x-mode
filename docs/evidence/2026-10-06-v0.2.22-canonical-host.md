## Runtime recovery

Recovery preserved the existing `gpt_key`, `provider_key`, and `mcp_key` identities from a protected deployment-evidence backup, changed the configured project cwd to `$HOME/codex-x-mode`, added current safe compatibility fields, and restored the private config with mode `0600`. No secret values were printed or committed.

After recovery, `http://127.0.0.1:8240/healthz` returned HTTP 200.
