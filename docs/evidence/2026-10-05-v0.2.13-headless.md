## Package-aware model policy

Packaged registry currently maps:

- `chatgpt-web/5.5` -> `gpt-5.5`
- `chatgpt-web/5.6-luna` -> `gpt-5.6-luna`
- `chatgpt-web/5.6-sol` -> `gpt-5.6-sol`

Visible models are `package registry ∩ authorized account catalog`.

Generic `chatgpt-web` uses an entitled configured default when available; otherwise it uses the highest-priority entitled packaged alias. This allows Free-like accounts to fall back to Luna and paid accounts with Sol entitlement to use Sol without hard-coding plan names.

A future package can add a Pro alias in the registry without changing routing core; it becomes visible only when the authorized account catalog also exposes the mapped underlying model.
