## Purpose

v0.2.21 keeps the Native-Codex-owned execution architecture from v0.2.20 and fixes the package metadata boundary for the bundled `codex-x-app-tool` Skill.

`skills/codex-x-app-tool/agents/openai.yaml` now explicitly declares an MCP tool dependency with `value: codex-x-app` for both CHAT and CODEX products. This binds the Skill to the MCP server that is already bundled by this plugin; it does not introduce an external plugin, Skill, browser, SIWC, Subscription Sharing, or custom-provider runtime dependency.

## Package contract

- Skill: `codex-x-app-tool`
- MCP server identifier: `codex-x-app`
- MCP endpoint: `/codex-x-app/mcp`
- Native protocol baseline: `codex-cli 0.160.1`
- Native transport: one lazy managed `codex app-server --stdio` process owned by the Codex X Mode runtime
- Runtime dependency on `codex-app-tools@openai-bundled`: forbidden

The existing 8 native-backed Codex X App tools remain unchanged: `list_threads`, `read_thread`, `create_thread`, `fork_thread`, `send_message_to_thread`, `set_thread_title`, `set_thread_archived`, and `wait_threads`.
