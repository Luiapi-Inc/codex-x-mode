## Root cause

The canonical host and bearer authentication were healthy, but Python urllib requests from the bundled verifier were rejected by Cloudflare before reaching the bridge.

Observed Cloudflare response:

- HTTP 403
- Error 1010
- browser_signature_banned
- detail identified the client browser signature as blocked

Same authenticated MCP initialize request, changing only User-Agent:

- Python-urllib/3.14 -> 403
- Codex-X-Mode-MCP/0.2.22 -> 200
- OpenAI-Connector/1.0 -> 200
- curl/8.7.1 -> 200
- Mozilla/5.0 -> 200

Therefore no Cloudflare policy weakening was required.

## Change

server/bridge/client.py now sends:

User-Agent: Codex-X-Mode-MCP/0.2.23

The regression test verifies the bundled MCP HTTP client sends this product User-Agent while preserving redirect refusal.

No model-routing, bearer-authentication, tunnel topology, Skill, SIWC-recovery, or Native Codex execution boundary was changed.
